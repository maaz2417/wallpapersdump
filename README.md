Wallpapers Dump

A personal collection of wallpapers that I like and use on my desktop.

This repository will be updated over time as I find and add more wallpapers.

Browse and Download

Open the folder containing the wallpaper you want.

Select the image.

Click Download raw file to download it in full resolution.

You can also clone the complete collection:

git clone git@github.com:maaz2417/wallpapersdump.git
